# Statut et indice de revendication

Le statut décrit uniquement les indications publiées par les sources : confirmé selon la source, revendiqué, revendication peu fiable ou non renseigné. L’indice reprend les marqueurs de crédibilité fournis, sans inventer de score numérique.

Le tableau affiche le statut et l’indice avec un filtre dédié. Le détail conserve les publications, catégories originales, dates et liens. Si une source déclare la revendication peu fiable alors qu’une autre la confirme ou la relaie comme revendiquée, la fiche indique « Sources divergentes ». Ces informations ne constituent pas une vérification indépendante de l’incident.
